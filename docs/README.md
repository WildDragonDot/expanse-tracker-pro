## Tech Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Prisma ORM
- **Database:** PostgreSQL (Supabase)
- **Deployment:** Vercel (Frontend), Render (Backend)
- **Authentication:** JWT
- **File Storage:** AWS S3
- **Email:** Mailgun
- **AI:** OpenAI GPT
